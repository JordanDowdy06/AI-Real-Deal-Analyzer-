# AI Real Deal ANalyzer

AI Real Deal Analyzer is an AI-powered real estate investment tool that help users analyze property deals using cash flow, ROI, cap rate, rehab costs, rental estimates, and market data.

## Features

- Analyze rental property deals
- Calculate monthly cash flow
- Estimate ROI and cap rate
- COmpare purchase price, rehab cost, and rental income
- Generate AI-powered deal insights
- Help investors decide if a deal is worth pursuing
